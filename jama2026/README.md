# JAMA2026 公開データ・再現パッケージ

塘 誠「経営方針で言明された指標の役員報酬への反映──EDINET/XBRLによる大規模アーカイバル分析──」
（日本管理会計学会『管理会計学』投稿中。2026年全国大会 自由論題での報告を改稿）の分析に用いた確定データと、
それだけで論文の主要数値を再現できる統計解析スクリプトです。

データベースへの接続は不要です。本ディレクトリのCSVとスクリプトだけで再現できます。

- **公開先**: https://github.com/tomoreal/edinet-xbrl-replication （`jama2026/` 配下）
- **DOI**: [10.5281/zenodo.21804805](https://doi.org/10.5281/zenodo.21804805)
  （全バージョンを代表するConcept DOI。常に最新版のレコードへ転送されます。
  バージョン固有のDOIは、転送先のZenodoのページに表示されます）

## 1. 構成

| ファイル | 内容 |
|---|---|
| `panel_kpi.csv` | KPI採用パネル。企業×断面が1行、4,057行（P期2,015社・P-4期2,042社） |
| `indicator_kpi.csv` | 指標名レベルの採用ダミー。P期の企業×指標名が1行、13,760行（2,015社×延べ93指標名） |
| `gold_set_kpi.xlsx` | 目視ゴールドセット。299社×2セクションの正解ラベルと、判定に用いた有報の該当セクション本文 |
| `gold_set_scoring.csv` | 上記の採点明細。doc_id×セクション×カテゴリーごとの目視ラベル（gold）・プログラムの判定（auto）・検出されたKPIラベル |
| `gold_set_holdout.xlsx` | ホールドアウトの目視ゴールドセット。上記299社を除いた同一母集団から同一の層化で抽出した100社×2セクション |
| `gold_set_holdout_scoring.csv` | ホールドアウトの採点明細（辞書・前処理を変更せず1度だけ採点した200判定） |
| `MANIFEST_kpi.txt` | 上記の行数・市場別内訳・SHA256・構築条件・列定義・カテゴリー定義 |
| `verify_kpi_from_csv.R` | **再現スクリプト**（`panel_kpi.csv` と `indicator_kpi.csv` を使用） |

ゴールドセットは第7節の抽出精度（適合率・再現率・F1）を第三者が確かめるためのものです。
`gold_set_scoring.csv` の gold と auto を突き合わせれば、下表の値がそのまま再現できます。

各ファイルのSHA256は対応するMANIFESTに記録しています。受領後に

```
sha256sum panel_kpi.csv        # Linux
shasum -a 256 panel_kpi.csv    # macOS
```

で照合してください。

## 2. 動作環境

再現スクリプトは **R** で書かれています。Pythonは再現には不要です
（データ生成側で用いており、参考として第5節に記載します）。

### R

| | |
|---|---|
| バージョン | R 4.3.3（2024-02-29）で動作確認 |
| 追加ライブラリ | **不要**（base Rのみで動きます） |

### データの所在

スクリプトはデータの場所を次の順に探すため、通常は設定不要です。

1. 環境変数 `JAMA2026_DATA`
2. スクリプトと同じディレクトリ（本パッケージをそのまま展開した場合）
3. カレントディレクトリ配下の `docs/JAMA2026_data`

別の場所にCSVを置く場合のみ、次のように指定してください。

```
JAMA2026_DATA=/path/to/data Rscript verify_kpi_from_csv.R
```

Rscript verify_kpi_from_csv.R     # 数十秒

## 4. スクリプトと論文の表の対応

| 出力見出し | 対応する箇所 |
|---|---|
| 1. セクション別のKPI採用率 | 表2（経営方針・役員報酬の各セクションにおけるKPI採用率） |
| 2. 経営方針で両カテゴリーを掲げた企業 | 表5（2×2クロス表）と4.1（反映率97%・39%、差+57pt、Tango 1998 の95%信頼区間、McNemar mid-p） |
| 3. 単独採用と併用 | 表4（単独／併用と併用率）と4.2 |
| 4. 反映率の時点間比較 | 4.4（P期とP-4期の反映率） |
| 5. 指標名レベルの一致率 | 5章（営業利益68%・当期純利益54%・売上高36%・ROE 32%ほか） |

再現される統計量は、2×2分割表のセル度数、報酬への反映率 a/(a+b)、McNemar検定のmid-p値、
対応あり標本の比率差の95%信頼区間、併用率、指標名レベルの一致率です。

> **注**: 論文が仮説の検定に用いるのは金額指標と財務比率の2カテゴリーで、非財務指標と
> 株主還元・株価関連指標は分析標本への組入れ判定にのみ用います。本スクリプトは4カテゴリー
> すべての採用率を出力するので、論文の表と対照する際は該当する行をご覧ください。

## 5. データの作り方（参考・再現には不要）

CSVは有価証券報告書のXBRLを解析したデータベースから生成しています。生成側の
スクリプトはリポジトリに含まれますが、実行には解析済みデータベース（数十GB）が
必要なため、本パッケージだけでは実行できません。

| スクリプト | 生成物 | 実行環境 |
|---|---|---|
| `db_exploration/export_kpi_panel.py` | `panel_kpi.csv`・`indicator_kpi.csv`・`MANIFEST_kpi.txt`・ゴールドセット4点の同梱 | Python 3.12.3、pandas 2.2.2 |
| `db_exploration/score_kpi_gold_set.py` | `gold_set_scoring.csv`（採点明細と精度指標） | Python 3.12.3、pandas 2.2.2 |

分析本体（`db_exploration/kpi_transmission_tables.py` 等）はPython
（pandas 2.2.2、SciPy 1.17.1、statsmodels 0.14.6）で実装しています。
これとは別に、データベースから標本を組み直してRで独立に再実装した検証
（`db_exploration/verify_in_r_kpi_mcnemar.R`）を行い、推定値が一致することを
確認しています。本パッケージのスクリプトは、その一段外側で「確定したCSVから
論文の表が導けること」を第三者が確認するためのものです。

## 6. データの内容に関する注意

- **企業の識別子はEDINETコード（`firm`）のみで、企業名は含みません。**
- `panel_kpi.csv` に収めるのはカテゴリー単位の採用ダミー（0/1）です。カテゴリーの定義
  （どのラベルがどのカテゴリーに属するか）は `MANIFEST_kpi.txt` に全件列挙しています。
- `indicator_kpi.csv` は、5章が引く指標名レベルの一致率を再現するために、同じ標本・同じ
  辞書のまま指標名（ラベル）単位の0/1を収めたものです。ラベルはキーワード辞書に依存する
  中間生成物で、辞書を更新すると値が変わるため、**本パッケージの版に固定した値**として
  お使いください。
- 分析基準日を固定した凍結データです（P期=2026年3月31日／P-4期=2022年3月31日）。
  元のデータベースは日次更新されるため、後日に再抽出しても同じ値にはなりません。
  再現には必ず本CSVを用いてください。
- 出典は金融庁EDINETで公開されている有価証券報告書です。二次利用にあたっては
  EDINETの利用規約をご確認ください。

## 7. KPI抽出手続の実装詳細（論文3.1の補足）

論文3.1では抽出手続の要点と検証結果のみを述べています。実装の詳細をここに記録します。
値はいずれも `panel_kpi.csv` を生成した時点（2026年9月5日）のものです。

### 7.1 対象テキストの取得

有価証券報告書のiXBRLテキストブロックを要素名で取得します。同一項目でも企業独自タグが
使われたり年度によってタグが変わったりするため（税務研究会 2023）、要素名の完全一致では
なく**語幹による照合**で吸収しています。

### 7.2 キーワード辞書

- 正規表現 **103パターン**（金額指標35・財務比率27・非財務指標32・株主還元・株価関連指標9）
  を**単一の情報源**（`company_kpis_config.py`）とし、セクション固有の
  辞書はこれを取り込んで拡張する構造です。役員報酬・経営方針・経営者分析の3セクションが
  同一の基底辞書を共有するため、セクション間の比較が辞書の差に汚染されません。
- ラベルの全件（どのラベルがどのカテゴリーに属するか）は `MANIFEST_kpi.txt` に列挙して
  います。
- 辞書は**開示テキストから帰納的に構築**しました。次の17語をトリガーとして全企業から
  候補語句を切り出し、頻度順に確認して指標名として機能している語のみを登録しています。

  > 業績指標、評価指標、KPI、評価項目、連動指標、評価用指標、具体的指標、算定基礎、
  > 数値目標、算定指標、算定方法、指標の選定理由、連動給与に係る指標、報酬に係る指標、
  > 業績に係る指標、指標として、指標は

  開示テキストから候補語を機械的に切り出して選別するという方針は、近藤・石光(2020)が
  マネジメント・コントロール単語の辞書を構築した手続と同様です。
- 地の文で頻出する語（人的資本・健康経営・DX推進・市場シェア・離職率など）は、施策の
  記述で誤検出するため意図的に登録していません。

### 7.3 KPIの抽出

**正規化・パターン走査・語境界判定**の3段で実装しています。

- 前処理でURL・略語直後の和文注記・定義式の右辺を除去します。
- 英字略語が英単語に埋没するマッチ（Performance の中の PER など）は語境界で排除します。
- 複合比率語は一体でマッチさせ、その内側の短い語を重ねて拾いません。たとえば
  「売上高営業利益率」から「営業利益率」を抽出した後に「売上高」を抽出することは
  ブロックされます。本稿の中心的対比は会計数値と財務比率という隣接カテゴリーの境界に
  あるため、この処理が結論を左右します。

### 7.4 ゴールドセットの構成と残存誤り

- **数値情報**: Financial Quest をゴールドセットとし、会計基準・業種・様式の違いに
  由来する計35種類のタグに対応したうえで直近6期（P期〜P-5期）を全社で突合しました
  （一致率：売上高99.3%、総資産99.8%）。
- **テキスト情報**: 市場区分と検出カテゴリー数で層化抽出した **299社**（分析標本2,015社の
  約15%、プライム149社・スタンダード150社、25業種に分散）の有価証券報告書を目視で確認し、
  **299社すべて**を採点しました（会計数値・財務比率の2カテゴリー×2セクションで計598判定）。
  対象企業の有報が後日訂正報告書に差し替えられた場合は、同一企業・同一決算期の現行docへ
  読み替えて採点します（ゴールドセットは固定標本なので、差替えのたびに痩せない）。

  | 指標 | 全体 | 役員報酬 | 経営方針 |
  |---|---|---|---|
  | 適合率 | 97.9% | 100.0% | 96.6% |
  | 再現率 | 99.6% | 98.9% | 100.0% |
  | F1 | 98.7% | 99.5% | 98.3% |

  同梱の `gold_set_scoring.csv` から再計算できます（`cat` が会計数字・財務比率の行に絞り、
  gold と auto を突き合わせる。列名の `会計数字` は本文の「金額指標」に対応します）。

- **ホールドアウト**: 上記299社は辞書の調整に用いた標本なので、汎化性能の推定ではありません。
  そこで299社を除いた同一母集団から同一の層化で **100社（200判定）** を新たに抽出し、辞書と
  前処理を一切変更せずに1度だけ採点しました。適合率96.9%・再現率97.7%・F1 97.3%、誤り12件の
  内訳は過検出7件・取りこぼし5件、経営方針側7件・役員報酬側5件です。同梱の
  `gold_set_holdout.xlsx` と `gold_set_holdout_scoring.csv` から再計算できます。

- **セクション間の対称性**: 誤り率にセクション間で有意差はありません（Fisherの正確確率
  検定で金額指標 p=0.106、財務比率 p=0.068。±5ポイントを margin とする同等性検定（TOST）でも
  同等と判定されます（p=0.014、0.011）。ホールドアウトでも有意差はありません（p=0.369、1.000））。
  一方のセクションだけを系統的に
  過検出・過小検出していれば、論文が観察する企業内の非対称性は抽出手続の産物でありうる
  ため、この確認が要になります。
- **残存誤り**: 598判定中18件（偽陽性15・偽陰性3）。最大の要因は施策・実績・構成比の
  本文からの過検出で、意味理解を要する原理的な限界です。辞書修正の各段階を通じて、
  会計数値・財務比率の対比の向きと有意性は一貫して変化しませんでした。

### 7.5 参考：役員報酬セクションでの頻出ラベル

採用率の高い順に、金額指標は営業利益・当期純利益・売上高・経常利益、財務比率はROE・
営業利益率・ROIC・経常利益率です。指標名ごとの採用社数と一致率は `indicator_kpi.csv` から
再現できます（`verify_kpi_from_csv.R` の出力5）。
